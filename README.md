# ☕ BrewBot – Coffee Shop Chat Assistant  

BrewBot is a lightweight, browser-based chatbot for a coffee shop.  
It can answer customer queries (menu, specials, hours, location) and also lets users add drinks to a cart with a running subtotal.  

Built with **HTML**, **TailwindCSS**, and **JavaScript**.  

---

## ✨ Features  
- 💬 **Interactive chat** – simple intent matching for greetings, hours, specials, vegan options, and location.  
- 🛒 **Menu & Cart** – add/remove items, live subtotal calculation.  
- 📂 **Persistence** – chat and cart are saved in LocalStorage (survive reloads).  
- 📑 **Export** – download chat history or a receipt as CSV.  
- 🧹 **Clear Chat** – reset conversation without affecting the cart.
